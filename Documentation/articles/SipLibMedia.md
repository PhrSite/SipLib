# The SipLib.Media Namespace

## Audio

The SipLib.Media namespace provides the following classes for encoding and decoding audio sample data.

| Codec Type | Encoder Class | Decoder Class |
|------------|---------------|---------------|
| G.711 PCMU | [PcmuEncoder](~/api/SipLib.Media.PcmuEncoder.yml)   | [PcmuDecoder](~/api/SipLib.Media.PcmuDecoder.yml)   |
| G.711 PCMA | [PcmaEncoder](~/api/SipLib.Media.PcmaEncoder.yml)   | [PcmaDecoder](~/api/SipLib.Media.PcmaDecoder.yml)   |
| G.722      | [G722Encoder](~/api/SipLib.Media.G722Encoder.yml)   | [G722Decoder](~/api/SipLib.Media.G722Decoder.yml)   |
| G.729      | [G729Encoder](~/api/SipLib.Media.G729Encoder.yml)   | [G729Decoder](~/api/SipLib.Media.G729Decoder.yml)   |
